# 實機驗證清單

每次一個遊戲、後端與瓶子。先記錄 macOS、晶片／RAM、顯示器與縮放、遊戲版本、後端、瓶子及 runtime 版本。A/B 比較需使用同版本遊戲、同後端、相同依賴及存檔副本；不要把「不同瓶子／不同設定」造成的差異直接歸因於引擎。

| 項目 | 操作 | 通過標準 |
|---|---|---|
| 安裝與校驗 | Install → Verify；再執行一次 Install | 校驗通過；重裝不覆寫瓶子／日誌 |
| 基本執行 | `--smoke --bottle smoke` | 32/64-bit 檔案與 BCrypt 正反向驗證 PASS |
| 女神守護之約／PR #2 | wined3d；Main.exe → 進入遊戲 → aLogin.exe | 登入／伺服器背景、按鈕、列表可見，非僅 BGM／游標；記錄約 50 秒載入與黑畫面是否分開 |
| BlueCG／A6 | wined3d；拖曳與連續縮放、最小化／還原、Alt+Enter、Retina | 畫面更新、大小及游標座標正確，沒有黑框、殘影、卡住 |
| 大富翁 4 | 相同 cnc-ddraw 與遊戲設定的瓶子副本 | 畫面、輸入與回合流程正常；此直接 launcher 不自動套用 App 的 CompatDB 規則 |
| 視窗幾何／PR #3 | 有框／無框、CEF、Retina 1x/2x、多螢幕、解析度切換 | client 區域未被裁掉，按鈕點擊位置與顯示一致 |
| Steam | 固定同一瓶子登入；關閉／再開 Steam | 登入保持、WebHelper 畫面與再次啟動正常 |
| CS2／DXMT | 保持 Steam；直接合法 Cities2.exe；另記正常 Paradox 流程 | 本機已知 winemetal 載入失敗；先確認是否同錯，若仍失敗，後續城市／Mods 列「未測」；不得算初始化成功 |
| CS2 視窗切換 | borderless、Exclusive Fullscreen；Cmd-Tab、最小化／還原、多螢幕 | 能恢復畫面與輸入，不凍結；每種模式單獨記錄 |
| CS2 遊戲內容 | 新城→遊玩→存檔→退出→重載→設定保存 | 城市／存檔／設定正常，無資料遺失 |
| Paradox Mods | 下載→重開→載入；再測重新下載 | 下載及載入完成，記錄模組名稱／版本與錯誤；不先套 cohtml 等 DLL 修補 |
| 影片／音訊 | 過場、跳過、音量、進出遊戲 | 影片可見、音訊正常，無黑畫面／退出卡住 |
| 長時間與效能 | 同一場景 30–60 分鐘；多次 Blt／切換 UI | 記錄 FPS、記憶體趨勢、卡頓與退出結果，不只憑一次啟動成功 |
| 楓之谷／其他遊戲 | 固定原本後端、依賴、登入路徑，單項 A/B | 沒有新增視窗、切換、音訊或退出問題；D3DMetal 另需自備 GPTK |
| 正常退出與回復 | 遊戲內正常退出，回到原版 Cyder | 測試程式結束；正式 runtime／瓶子保持原狀 |
