# Wine 11.8 更新清單

範圍 `wine-11.7..wine-11.8`，release commit `71e7a2e81eec9155d5d0745b491e1cbfab3bf742`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.8/ANNOUNCE.md)。

Mono 11.1.0、MSXML、XKBRegistry 鍵盤配置、VBScript。
