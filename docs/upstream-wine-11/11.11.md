# Wine 11.11 更新清單

範圍 `wine-11.10..wine-11.11`，release commit `f6c044e1890e84a4aa5e77e76ba7276a615630e1`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.11/ANNOUNCE.md)。

內附 SymCrypt 取代 TomCrypt、USER32 window info shared memory、Wayland layered windows、VBScript。
