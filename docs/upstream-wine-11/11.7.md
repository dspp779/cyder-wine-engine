# Wine 11.7 更新清單

範圍 `wine-11.6..wine-11.7`，release commit `f051a28829e589b5cf025c574cb16fcf7aeb345a`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.7/ANNOUNCE.md)。

MSXML 移除 libxml2 起步、VBScript、D3DX sRGB filter、DirectSound 7.1。
