# Wine 11.4 更新清單

範圍 `wine-11.3..wine-11.4`，release commit `cc893ef9cb17b994bfd1f1a1f7355be55e615623`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.4/ANNOUNCE.md)。

MSXML SAX 重寫、DirectSound 重採樣、CFGMGR32、Unix 時區配對。
