# Wine 11.15 更新清單

範圍 `wine-11.14..wine-11.15`，release commit `2df1ee28039cf84776eb1421ed90bd154cebb65f`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.15/ANNOUNCE.md)。

BCrypt KDF、Mingw ARM64EC 建置、WindowsCodecs、local NTLM。
