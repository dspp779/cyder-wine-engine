# Wine 11.14 更新清單

範圍 `wine-11.13..wine-11.14`，release commit `1012f3d99507b80d4869eabf0853567660a7ecbb`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.14/ANNOUNCE.md)。

DirectSound 7.1 格式轉換、BCrypt AES-GMAC、FreeBSD 新 WoW64、Start Menu 圖示。
