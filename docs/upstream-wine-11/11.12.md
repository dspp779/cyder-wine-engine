# Wine 11.12 更新清單

範圍 `wine-11.11..wine-11.12`，release commit `996020f410e7a1aa2dd6b44cf740854ea524d31a`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.12/ANNOUNCE.md)。

內附 FFmpeg libswresample／libswscale、Mono 11.2.0、MSXML XSLPattern。
