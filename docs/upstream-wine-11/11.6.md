# Wine 11.6 更新清單

範圍 `wine-11.5..wine-11.6`，release commit `6e073d28dee3af7f4c965daec94644e0f9f92727`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.6/ANNOUNCE.md)。
