# Wine 11.3 更新清單

範圍 `wine-11.2..wine-11.3`，release commit `222c976140d1b66c71769296f856f6523782b6c9`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.3/ANNOUNCE.md)。

Mono 11.0.0、vkd3d 1.19、DirectSound FIR、PDB、Aero theme。
