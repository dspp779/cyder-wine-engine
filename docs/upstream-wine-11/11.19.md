# Wine 11.19 更新清單

範圍 `wine-11.18..wine-11.19`，release commit `455e3509b98a6919fd4ad1def4803e08c41c03b2`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.19/ANNOUNCE.md)。
