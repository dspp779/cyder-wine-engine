# Wine 11.2 更新清單

範圍 `wine-11.1..wine-11.2`，release commit `87ba10bb3aa8ea636dff5c2030b376da1627910a`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.2/ANNOUNCE.md)。

PDB 載入最佳化、C runtime 的 MSVC constructor、版本資源機制。
