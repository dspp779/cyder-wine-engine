# Wine 11.20 更新清單

範圍 `wine-11.19..wine-11.20`，release commit `7298a818b79446bae153b8d5aa27235ab3703bf9`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.20/ANNOUNCE.md)。

ARM64EC relay debugging、XML validation、CDROM 移往 Mount Manager。
