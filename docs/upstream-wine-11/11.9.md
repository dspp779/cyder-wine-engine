# Wine 11.9 更新清單

範圍 `wine-11.8..wine-11.9`，release commit `0c0d26432084c18213d5c4b343f10939d25eee2c`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.9/ANNOUNCE.md)。

內附 SQLite、system thread 起步、ARM64 模擬碼執行緒暫停、VBScript。
