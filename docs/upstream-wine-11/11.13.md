# Wine 11.13 更新清單

範圍 `wine-11.12..wine-11.13`，release commit `6eb2e4c32cc9e271856146df11ed3a5c2cf29234`。
[官方公告](https://github.com/wine-mirror/wine/blob/wine-11.13/ANNOUNCE.md)。

input pointer、X11 scancode、ARM64EC FFmpeg 最佳化。
